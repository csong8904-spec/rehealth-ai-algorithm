# 算法设计说明书 v0.1

## 1. 算法定位

算法名称：ReHealth AI健康趋势报告生成合成算法。

算法面向已经明确授权数据处理的成年用户，对可穿戴设备时序数据及用户填写的基础健康
资料进行分析，形成结构化趋势事实，并合成自然语言健康趋势报告。输出用于健康管理和
复测提醒，不用于疾病诊断、治疗决策、处方生成或急救判断。

## 2. 输入与输出

### 2.1 输入

- 时间戳；
- 心率或脉率；
- 三轴加速度或设备汇总的活动量；
- 睡眠时长、睡眠区间及睡眠阶段（可选）；
- 血氧、皮肤温度、呼吸率（可选）；
- 年龄段、性别、身高、体重等用户主动提供的资料（可选）；
- 用户目标与报告周期。

第一版不接收姓名、身份证号、精确住址、面部、声纹或原始定位轨迹。业务标识与算法侧
使用的随机用户标识分离存储。

### 2.2 输出

- `data_quality_score`：数据质量分数；
- `trend_facts`：经过校验的趋势事实；
- `anomaly_score`：相对个人基线的异常程度；
- `risk_level`：低、中、高三级非诊断性风险提示；
- `confidence`：输出置信度；
- `evidence`：生成报告引用的结构化依据；
- `report_text`：合成的健康趋势报告；
- `synthesis_label`：合成内容标识；
- `safety_actions`：安全层采取的阻断或降级措施。

## 3. 模型结构

### 3.1 数据质量门控网络 Q-Net

按传感器类型进行重采样、单位统一、缺失掩码构造和鲁棒标准化。Q-Net使用一维卷积提取
局部波形质量特征，结合设备佩戴状态及运动强度，输出每个时间窗的质量权重 `q_t`。

低质量时间窗不会直接删除，而是降低在后续注意力聚合中的权重。若有效数据不足，系统
不生成风险结论，仅输出补充数据提示。

### 3.2 个体基线模块 B-Net

对满足最低质量条件的历史数据建立滚动基线。基线包括中位数、四分位距、昼夜节律、
工作日/休息日差异及同一活动强度下的心率分布。

模型同时使用群体归一化值和个人偏差值：

```text
z_personal(t) = (x(t) - median_personal) / (IQR_personal + epsilon)
```

当个人数据不足时，只能使用保守的群体先验，并显著降低置信度。

### 3.3 多尺度时序编码器 H-Encoder

编码器由三部分构成：

- 多尺度膨胀一维卷积：捕获分钟至小时级变化；
- 缺失感知门控单元：同时输入观测值、缺失掩码和距上次观测的时间；
- 稀疏时序注意力：捕获日级和周级趋势。

编码结果包含短期状态向量、长期趋势向量以及数据质量加权后的全局向量。

### 3.4 多任务预测头

模型联合优化以下任务：

1. 下一时间窗生理指标预测；
2. 个人基线偏离预测；
3. 活动状态与恢复趋势估计；
4. 数据质量与不确定性估计；
5. 有人工标签时的异常风险分类。

总损失为：

```text
L = w1*L_forecast + w2*L_deviation + w3*L_activity
  + w4*L_quality + w5*L_risk + w6*L_calibration
```

风险输出必须经过温度缩放或保序回归校准。阈值在独立验证集上确定，并按设备型号和主要
人群分层复核。

### 3.5 事实约束生成器 R-Generator

预测模块先输出结构化事实包，文本生成器不能直接读取未经处理的原始健康数据。事实包
只包含数值区间、方向、置信度、证据时间范围和允许使用的建议类别。

生成器采用受控解码：

- 必须引用事实包中的指标；
- 不得新增疾病、药品或治疗事实；
- 不得输出“确诊、治愈、保证、必须服药”等禁止表述；
- 高风险或低置信度场景采用固定安全模板；
- 生成文本经过第二次事实一致性检查；
- 输出显式合成提示，并在日志中保存模型和策略版本。

生产版本可以采用公司自训的小型文本生成模型，或调用已经完成相应备案/登记且合同允许
商用的第三方模型。若使用第三方模型，备案材料中应真实说明调用关系，不能描述为完全
自研基础模型。

## 4. 训练数据计划

### 4.1 公开数据预训练

- PPG-DaLiA：PPG运动伪影抑制、心率估计；
- Wrist PPG During Exercise：跨设备运动场景验证；
- BIDMC PPG and Respiration：PPG与呼吸率辅助任务验证。

每个数据集建立数据来源、版本、许可证、下载日期、哈希、用途和署名记录。

### 4.2 公司数据校准

公开数据只用于预训练和原型验证。上线前需取得公司合法采集的目标设备、目标地区和目标
人群数据，用于设备适配、概率校准、阈值确定及外部验证。

训练集、验证集和测试集必须按受试者划分，严禁同一人的不同窗口跨集合，以防数据泄漏。

## 5. 评估指标

- 信号估计：MAE、RMSE、覆盖率；
- 风险识别：AUROC、AUPRC、灵敏度、特异度、F1；
- 概率可靠性：Brier Score、ECE、校准曲线；
- 生成质量：事实一致率、证据覆盖率、禁止表述触发率；
- 安全性：诊断越界率、处方越界率、隐私泄漏率；
- 公平性：按年龄段、性别、肤色代理因素及设备型号分层评估；
- 鲁棒性：缺失、噪声、设备脱落、时间漂移和异常输入测试。

## 6. 安全与人工干预

- 出现胸痛、严重呼吸困难、晕厥等用户主动描述的急症信号时，不运行普通生成流程，直接
  显示预先审核的紧急就医提示；
- 数据不足或冲突时不输出高确定性结论；
- 用户能够查看、纠正或删除个人资料，并关闭个性化报告；
- 建立申诉、投诉、报告更正和模型回滚机制；
- 每次输出记录输入摘要哈希、模型版本、规则版本、风险值、生成内容及安全处置结果；
- 生产日志按必要期限保存，并进行访问控制、脱敏和审计。

## 7. 可形成公司自主资产的部分

- 多尺度缺失感知时序编码器的具体结构和参数；
- 个人基线与群体先验的融合方法；
- 多任务损失权重及训练流程；
- 异常分数融合与风险阈值；
- 事实包协议、受控生成策略与事实一致性校验；
- 公司采集的数据、标注规范、模型权重和评估集。
