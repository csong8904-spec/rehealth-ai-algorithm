# ReHealth AI模型卡 v0.1

## 当前状态

本版本是工程验证模型，不是生产模型、临床模型或备案效果证明。风险模型当前使用合成数据
训练，只用于证明从特征提取、训练、模型保存、推理、报告生成到安全拦截的链路可以运行。

PPG运动融合模型已完成按受试者留一验证：中位绝对误差5.65 bpm、误差不超过10 bpm的
记录占比61.11%，但平均误差24.06 bpm且P90误差69.28 bpm。主要风险是半频/倍频混淆。
该模型状态为`blocked-from-production`。

加入半频/倍频歧义拒答后，已接受记录的平均误差降至6.67 bpm，且全部落在10 bpm以内，
但覆盖率仅16.67%。由于覆盖率过低，仍不得发布。

`temporal-decoder-v1`曾尝试以跨窗口连续性抑制倍频跳变，但受试者隔离验证MAE为
29.90 bpm，低于基线表现。该候选已被拒绝，不应部署；评测文件仅用于记录模型晋级流程
能够发现并阻止性能回退。

`adaptive-denoise-v1`使用加速度参考的窗口内岭回归去除PPG运动相关分量。其受试者隔离
验证MAE为19.70 bpm、P90为56.06 bpm、误差不超过10 bpm的记录占比为66.67%，优于
候选排序基线的主要总体指标，现作为研究领先候选保存。由于仍未通过冻结门槛，该身份不
表示可上线、可医疗使用或可作为备案效果证明。

`adaptive-denoise-group-softmax-v1`的MAE为21.44 bpm，未超过当前研究领先候选，已被
拒绝。该结果说明仅改变候选排序损失不足以解决持续性运动谐波问题。

## 预期用途

- 成年用户的可穿戴数据质量检查；
- 相对个人历史基线的趋势计算；
- 非诊断性异常风险提示；
- 基于结构化事实的健康趋势报告生成。

## 禁止用途

- 疾病诊断、鉴别诊断或治疗决策；
- 药物推荐、处方生成或更改医嘱；
- 急救判断；
- 保险、招聘、信贷等对用户权益有重大影响的决定；
- 未经监护人和合规流程处理未成年人数据。

## 上线前替换项

- 用合法取得的真实数据替换合成训练数据；
- 将确定性报告生成器替换为已完成许可证复核和安全微调的本地生成模型；
- 固化生产阈值、概率校准器和设备适配参数；
- 完成外部验证、公平性、鲁棒性、隐私和红队测试；
- 完成个人信息保护影响评估和备案材料复核。
