# 生产发布与备案前检查表

## 模型和数据

- [ ] 底座具体版本、revision、权重哈希和许可证快照已归档；
- [ ] 所有训练数据均有来源、授权、版本、用途和删除机制记录；
- [ ] 合成训练样本已由专业人员复核，`review_status`不再为`not-human-reviewed`；
- [ ] 真实数据按用户划分，黄金测试集从未参与训练或调参；
- [ ] 生产风险阈值和概率校准器已经冻结；
- [ ] 模型卡、限制和已知风险已经更新。

## 深度合成服务

- [ ] 实际服务使用深度生成模型，而非仅用模板拼接；
- [ ] 生成内容包含显式标识；
- [ ] 文件或响应元数据中的隐式标识方案已实现并验证；
- [ ] 模型版本、提示词版本、输入摘要和输出结果可审计；
- [ ] 用户协议和产品页面说明服务使用深度合成技术；
- [ ] 备案编号取得后在规定位置公示并提供链接。

## 健康和医疗边界

- [ ] 不宣传疾病诊断、治疗效果、处方或急救能力；
- [ ] 诊断、药品、治疗保证和高危提示词红队测试通过；
- [ ] 数据不足、模型不确定和设备异常场景能够可靠降级；
- [ ] 高风险输出存在人工审核或固定安全处置流程；
- [ ] 已完成是否涉及医疗器械软件的分类界定评估。

## 数据与用户权益

- [ ] 医疗健康敏感个人信息已取得适用的单独同意；
- [ ] 已完成个人信息保护影响评估；
- [ ] 已实现访问、更正、删除、撤回同意和关闭个性化功能；
- [ ] 未成年人入口、监护人流程和限制已完成；
- [ ] 投诉举报、申诉、人工干预和应急响应流程已演练。
