PRIVACY NOTICE / 隐私说明

Research site privacy notice

This page describes the intended data handling of the ai.jsruihe.cn research showcase. Before launch, the operator must check the actual server logs, analytics, CDN, and third-party settings, then update this notice accordingly.

Health data

The showcase displays fixed synthetic examples. It has no health-data entry or upload feature and does not produce live personal health reports. Please do not post personal health information in public GitHub issues.

Website access data

The page sets no analytics cookies and stores no report or health data in the browser. The server, reverse proxy, or cloud provider may record access time, request path, IP address, and browser information for security and troubleshooting. The operator must confirm and disclose actual retention practices before launch.

External links

Links to the company website and public GitHub repository are governed by those sites' own privacy practices.

Future live service

A live personal report service needs its own complete privacy policy, consent and withdrawal controls before any health-data intake. This research-site notice does not substitute for those rules.
